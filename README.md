# num_series: Пакет алгоритмической обработки числовых рядов

Лабораторная работа №5

##  Структура

Для работы с проектом достаточно скопировать папку с пакетом. Внешние зависимости отсутствуют (используется только стандартная библиотека Python 3.8+).

Структура проекта:
```text
.
├── num_series/
│   ├── __init__.py          # Публичный API пакета
│   ├── generator.py         # Генераторы рядов (random, sine, trend)
│   ├── stats.py             # Базовая статистика (mean, median, etc.)
│   ├── moving_average.py    # Скользящие средние (SMA, CMA, EMA)
│   ├── io_json.py           # Сохранение и чтение JSON
│   └── io_file.py           # Чтение текстовых файлов (txt, csv)
└── main.py                  # Точка входа CLI (демонстрация)
